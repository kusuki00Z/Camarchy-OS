# Camachy-OS
This is my attempt to create my own ISO with CachyOS as the base, and Omarchy on top as DE. 

# Goals
- Create ISO
  - Maybe also install script for existing CachyOS?
- ISO installs CachyOS, then installs Omarchy
- The OS needs to use CachyOS as base, so any updates will pull from Cachy repo
- DE updates need to be pulled from Omarchy repo
